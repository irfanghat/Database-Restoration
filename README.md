### Database Restoration

This repository contains very basic examples on how database restoration works.
It includes basic scenarios such as corrupting data stored in multiple tables and or deleting a database entirely.
**Backups** are essentially copies of a database that can be restored. This includes tables, constraints, data, objects and additional informations about the database.

See:
- [Postgres](/postgres/)
- [MySQL](/mysql/)


## Postgres

Restoration procedures for [Postgres](https://www.postgresql.org/) are done via `pg_dump` and `pg_restore`.
